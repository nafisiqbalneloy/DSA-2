# 🧩 Data Structures & Algorithms 2 (C++)

Lab solutions and practice for my second DSA course, focused on algorithm design: dynamic programming, greedy methods and graph algorithms, all in **C++**.

## 📂 Algorithms implemented

| File | Topic |
|---|---|
| `01knapsack.cpp` | **0/1 Knapsack** with dynamic programming, tracing back the chosen items |
| `dijkstra.cpp` | **Dijkstra's** shortest path on a graph class |
| `MST_Kruskal.cpp` | **Kruskal's** minimum spanning tree using a Disjoint Set (union-find) |
| `countFrequencey.cpp` | Frequency counting with `map` |
| `employee.cpp`, `studentLore.cpp` | Class-based problems with sorting on custom objects |
| Numbered lab files (`…_01` to `…_04`, `…_1` to `…_3`) | Lab tasks covering subarray problems, sorting and custom classes |
| `d1.cpp`, `q1.cpp`, `prac1.cpp`, `increment.cpp`, `rough*.cpp` | Practice and scratch work |

## ▶️ Running

```bash
g++ -std=c++17 dijkstra.cpp -o dijkstra
./dijkstra
```
